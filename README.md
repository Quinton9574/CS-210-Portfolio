# CS 210 – Project Three: Corner Grocer

## Project Summary
For this project, I created a C++ program that helps Corner Grocer track how often grocery items are purchased. The program reads information from a file, counts the frequency of each item, and displays the results through different menu options. The goal was to help the grocery store better understand purchasing patterns and manage inventory.

## What Did I Do Particularly Well?
I did well organizing the program and making the menu easy to follow. I also improved my ability to use loops, functions, and conditional statements. I was able to work through the programming requirements and develop a solution that displays grocery information in a useful way.

## Where Could I Enhance My Code?
I could improve my program by adding more input validation and error handling. For example, I could make sure the program responds properly when someone enters an invalid menu choice or when a file cannot be opened. These improvements would make the program more reliable and secure.

## What Was Most Challenging?
The most challenging part was understanding file handling and counting how often each grocery item appeared. I overcame these challenges by reviewing course materials, testing my program in Codio, and correcting errors as I found them. I also learned how helpful programming documentation and additional practice can be when solving problems.

## What Skills Are Transferable?
This project helped me develop skills in C++ programming, debugging, file handling, problem-solving, and organizing data. These skills will be useful in future computer science courses and software development projects.

## How Did I Make My Program Maintainable, Readable, and Adaptable?
I worked to keep my code organized by using separate functions for different tasks. I also used understandable variable names and consistent formatting. This makes the program easier to read, maintain, and improve. In the future, I could add more features without having to rebuild the entire program.

## Final Reflection
This project helped me gain more confidence in programming with C++. I learned how to break down larger problems into smaller tasks and how to troubleshoot mistakes. As I continue working toward my Computer Science degree, I plan to build on these skills and use this project as part of my programming portfolio.
